# Dry run pitches

Twelve pitches, one format per column. **Whatever is not picked as a dry run
becomes the launch bank**, which is four pieces needed anyway.

Read `UNVERIFIED.md` before using any number here.

## Picked

`calibration/2026-09-17-dry-run-picks.json` records **one of three** locked:

- **under.the.hood:** `lid1`, Meta put an agent in front of two billion people.
- **follow.the.money:** not picked.
- **mind.the.gap:** not picked.

The template is not fixed until all three are written and judged. That is the
gate on phase 5 and everything after it.

## The three treatment axes

Each picked subject gets written three ways, and each axis changes a different
thing:

- **A, the opening.** Cold on the number, cold on the scene, cold on the claim
  being quoted back. Tests what makes him keep reading.
- **B, the spine.** Chronological walk-through, against mechanism then
  counterpoint, against evidence first with the argument assembled at the end.
  Tests how much structure the engine can template.
- **C, the temperature.** Dry and forensic, against warm and energetic, against
  openly funny. All three inside the no-preaching rule. Tests where the register
  actually sits.

Each winner is then rebuilt as written, audio and vertical video, because that
is where the template stops being theoretical.
